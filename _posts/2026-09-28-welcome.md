This is the first post. Every post is a Markdown file in `_posts/`, named
`YYYY-MM-DD-some-title.md`, with a small block of front matter at the top:

```yaml
---
title: "My post title"
description: "Optional one-line summary shown on the home card."
image: /assets/posts/cover.jpg   # optional card cover
---
```

Commit and push — GitHub Pages rebuilds the site in about a minute.
